# Баланс оружия — шаг 2.12

Сгенерировано `tools/ttk_report.gd` из `src/weapons/data/balanced_catalog.tres`. Повторная генерация (PowerShell): `& $env:GODOT --headless --path . -s res://tools/ttk_report.gd`.

Состав согласован пользователем: **17 единиц**, включая подствольный гранатомёт. Временные `sample_*` не входят в каталог и сохраняются для прежних тестов/комплекта.

## Методика

Цель: 100 HP, без брони/регенерации; симуляция 60 Гц. Первый выстрел — t=0; все выстрелы и все дробины попадают в выбранную зону. TTK — нижняя граница без ADS, смены, перезарядки, промахов и сетевой задержки.

Урон = `damage_at(distance) × pellets × множитель хитбокса`; число выстрелов = `ceil(HP / урон)`. Интервал = `max(1, ceil(60 / RPM × Гц))` тиков; для SEMI минимум 2 тика, чтобы отпустить спуск. TTK = `(выстрелы − 1) × интервал / Гц`. Ячейка: **выстрелы / секунды**; 0.000 означает убийство первым выстрелом.

Множители из `default_hitboxes.tres`: торс 1.00, голова 2.00. Поля WeaponData.headshot_mult/limb_mult повторно не применяются: это соответствует DamageCalc. Используется первый режим профиля; SEMI требует идеальных повторных нажатий. `—` означает: снарядный профиль, цель вне hitscan_range, неверные параметры, недостаточно одного магазина либо требуется повторный запуск очереди.

Ориентир средней дистанции для AR: **25–50 м, 0.25–0.40 с в торс**. У дробовиков таблица предполагает попадание всех дробин даже вдали; реальная эффективность ниже. Гранатомёт не получает фиктивный hitscan-TTK: полёт, гравитация и место взрыва меняют результат.

## Человеческая приёмка

🧑 Требуется проверка человеком **каждого из 17 профилей**; статус шага REVIEW до подтверждения. Оценка ощущений пока не проведена. Все профили используют существующие процедурные модель/звук.

Запуск выбранного профиля (PowerShell): `& $env:GODOT --path . -s res://tools/weapon_balance_acceptance.gd -- --weapon=kestrel_ar`. Заменить ID на любой из таблицы; исходные сцена и стандартный комплект на диске не изменяются. Без `--weapon` скрипт автоматически проверяет стрельбу всех 17 профилей на полигоне.

Для каждого профиля: стрельба одиночными/очередями, ADS, движение, стоя/присяд/лёжа, пустая и тактическая перезарядка; мишени на 5/10/25/50/100/200 м. У снайперских проверить голову, у дробовиков распределение дроби, у гранатомёта дугу/взрыв/стену. Записать отзыв и поправить соответствующий `.tres` в `src/weapons/data/catalog/`, затем повторить генерацию отчёта и `tools/check.sh`.
